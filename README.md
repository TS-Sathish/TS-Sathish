### 🚀 Featured projects
**[Sentinel Claims Intelligence](https://github.com/TS-Sathish/sentinel-claims-intelligence)**
Insurance claim risk triage on 15,420 vehicle insurance claims (Kaggle fraud dataset, 6% fraud rate). An XGBoost classifier ranks claims for review (ROC-AUC 0.76, 76% recall, beating a logistic regression baseline), an Isolation Forest adds a separate anomaly signal, and SHAP explains every score. Results are served through a FastAPI API and an 8-page Streamlit dashboard, with SQLite audit history and optional GenAI review notes. Sensitive attributes (age, sex, marital status) are excluded from scoring, and the tool supports human reviewers rather than making claim decisions.

`Python` `XGBoost` `Isolation Forest` `SHAP` `FastAPI` `Streamlit` `SQLite` `pytest` `GitHub Actions`

**[Customer Risk & Retention Intelligence](https://github.com/TS-Sathish/customer_risk_retention_webapp)**
Predicts customer churn on the IBM Telco dataset (7,043 customers) with XGBoost and logistic regression, segments customers with K-Means, explains predictions with SHAP, and serves results through a FastAPI API and a Streamlit dashboard. Includes tests, a model card and documented limitations.

`Python` `XGBoost` `SHAP` `FastAPI` `Streamlit` `SQLite` `pytest`
